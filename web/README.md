# BlockTrellis

Website for [blocktrellis.com](https://blocktrellis.com) — a blockchain data engineering platform that turns raw Arc Mainnet data into canonical datasets.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Purpose |
| --- | --- |
| `/` | Product homepage |
| `/datasets` | Data catalog |
| `/docs` | Developer documentation |
| `/research` | Protocol and methodology notes |
| `/engineering` | Engineering methodology |
| `/build-log` | Public build log |
| `/architecture` | Pipeline layers |
| `/status` | Network and data status |
| `/explore` | Lightweight explorer (beta) |
| `/api` | REST API reference |
| `/about` | Project and roadmap |

Visual language and information architecture follow `../demo/chainforge_website_prototype_brief.md` and the bundled design skeleton in `../demo/ChainForge.html`.
